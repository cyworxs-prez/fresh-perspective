# Shared Intelligence Tradecraft Skills

Reusable methods that support analysts across Joint, Service, Intelligence Community, interagency, and other analytic environments.

These skills address capabilities that are substantially common across organizations: task scoping, evidence organization, structured analytic techniques, assumptions, uncertainty, assessment language, and product quality. A Joint or Service-specific skill may call these shared skills and then apply its own doctrinal terminology and required artifacts.

## Operating principle

The model is a tradecraft assistant. It does not become the analyst, select a mission, invent reporting, determine classification, assign final confidence, or approve an intelligence product.

Every skill begins with an interview. The assistant must confirm the decision context, intelligence question, audience, scope, evidence, handling restrictions, deliverable, and review authority before substantive processing.

## Initial skills

- `analyst-interview-and-scope/` — establish and confirm the task profile before analysis.
- `evidence-and-claim-ledger/` — decompose claims and preserve evidence traceability.
- `structured-analytic-techniques/` — select and facilitate an appropriate structured technique.
- `assessment-language-and-confidence/` — help the analyst express likelihood, uncertainty, and confidence consistently.
- `intelligence-requirements-and-collection-support/` — convert validated gaps into candidate PIRs, EEIs, SIRs, RFIs, and a tracked collection-support matrix without tasking collection.

## Recommended sequence

1. Run `analyst-interview-and-scope`.
2. Build or update the evidence-and-claim ledger.
3. Select structured techniques based on the decision, uncertainty, and failure mode.
4. Draft key judgments using the assessment-language skill.
5. Apply the relevant Joint, Service, IC, or organizational review skill.
6. Obtain human approval before finalization or dissemination.

## Required working artifacts

Depending on the task, retain:

- confirmed analysis profile;
- information cutoff and source-access note;
- claim-and-evidence ledger;
- assumptions register;
- alternative hypotheses or scenarios;
- uncertainty and confidence rationale;
- collection or research gaps;
- key-judgment register;
- review findings and analyst adjudication.

## Limitations

These skills provide a public, organization-neutral baseline. Current command, agency, product-line, classification, disclosure, records, privacy, and supervisory requirements govern actual production.
