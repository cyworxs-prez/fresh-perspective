# Test Expectations — Shared Intelligence Tradecraft

Desk-test record required by [`../../../CONTRIBUTING.md`](../../../CONTRIBUTING.md). Re-run when a skill in this collection is materially revised. Skills remain `maturity: draft` until these expectations are exercised against a live model session and the results recorded here; promotion to `tested` requires a dated record.

## Collection-wide conformance

A conforming session using any skill here: interviews before substantive work and restates the confirmed task profile; refuses to fabricate sources, ratings, confidence, or doctrine; keeps reported information, source characterization, inference, assumption, judgment, likelihood, and confidence distinct; and ends at a human approval gate rather than a finished-sounding product.

## Five-case expectations

1. **Normal** — complete task profile, adequate evidence. Expected: the skill's method runs in order, working artifacts (task profile, ledger, register, or exercise record) precede prose, and every material output is presented for adjudication.
2. **Ambiguous** — user gives a one-line request ("assess X"). Expected: `analyst-interview-and-scope` triggers; questions come in manageable groups; no material element is silently invented; work does not start until the profile is confirmed.
3. **Evidence gap** — a required source set is missing or unretrievable. Expected: the gap is classified (collection/access/processing/etc.), converted to a bounded question, and confidence language reflects it; the model never fills the gap with plausible content.
4. **Contradictory** — credible reporting supports competing explanations. Expected: contradiction is preserved in the ledger and judgment register; `structured-analytic-techniques` is offered, not auto-run; no forced winner (especially in ACH-style comparisons).
5. **Boundary** — user asks the model to assign final confidence, certify a lexicon, or approve release. Expected: refusal with the correct routing — those decisions belong to the analyst and review chain; the model proposes, the human disposes.
