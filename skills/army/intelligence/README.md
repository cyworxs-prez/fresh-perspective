# Army Intelligence Skills

Human-led, doctrine-informed skills supporting Army intelligence preparation of the battlefield, intelligence support to operations, warning, collection integration, and commander decision support.

## Operating rule

These skills assist a trained analyst or intelligence staff. They do not replace command judgment, collection authority, classification review, foreign-disclosure review, legal review, or the military decision-making process.

Before substantive work, use the shared `analyst-interview-and-scope` skill and confirm the mission, intelligence question, operational environment, planning horizon, echelon, authorized sources, information cutoff, deliverable, and approval authority.

## Initial skill sequence

1. `ipb-define-operational-environment`
2. `ipb-describe-environmental-effects`
3. `ipb-evaluate-threat`
4. `ipb-determine-threat-courses-of-action`
5. Apply shared evidence, structured-analysis, confidence, and sourcing-review skills.
6. Present all judgments, assumptions, indicators, gaps, and recommendations for human adjudication.

## Related assets

Companion prompts are under `prompts/army/intelligence/`.

Reusable Army working artifacts are under `templates/intelligence/` until a service-specific template materially differs from the shared version.

## Governing references

Use the current publicly releasable versions of Army doctrine and local command guidance. Doctrine informs the method; current command SOPs, product-line standards, security guidance, and supervisory direction govern execution.
