# Shared Intelligence Tradecraft Prompts

Interview-first prompts that implement the shared intelligence-tradecraft skills in a model-ready form.

These prompts are designed to support a trained human analyst. They do not authorize autonomous intelligence production, source fabrication, classification decisions, dissemination, collection tasking, or final analytic judgment.

## Operating sequence

1. Use `interview-and-scope.md` to confirm the task profile.
2. Use `build-evidence-ledger.md` to organize reporting and claims.
3. Use `select-and-run-sat.md` when structured challenge or alternative analysis is needed.
4. Use `draft-key-judgments.md` to support analyst-approved assessment language and confidence.
5. Apply the relevant Joint, Service, IC, or organizational review prompt.

## Prompt requirements

Every prompt in this collection must:

- identify the model as an assistant to the human analyst;
- interview before substantive work;
- confirm the final task profile;
- use only authorized, identified sources;
- preserve fact, inference, assumption, judgment, likelihood, and confidence distinctions;
- surface contradictions, alternatives, and gaps;
- prohibit fabricated evidence, citations, doctrine, and confidence;
- require human adjudication and approval.
